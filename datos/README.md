# Datos

La base de la ENUSC 2023 no se sube al repositorio por su tamaño (~225 MB). Descárgala y déjala en esta carpeta con este nombre:

```
datos/
└── base-usuario-20-enusc-2023.csv
```

| Archivo | Descarga |
|---|---|
| Base de usuario ENUSC 2023 (CSV) | [ine.gob.cl](https://www.ine.gob.cl/docs/default-source/seguridad-ciudadana/bbdd/2023/base-usuario-20-enusc-2023.csv?sfvrsn=34653b72_2&download=true) |
| Diccionario de variables y documentación | [ine.gob.cl/enusc](https://www.ine.gob.cl/enusc) |

El diccionario de variables es necesario para interpretar los códigos de cada pregunta (por ejemplo, 1 = Sí, 2 = No, 88 = No sabe, 99 = No responde).
